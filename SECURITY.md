# Security / Segurança / Seguridad

## PT-BR

Antes de publicar ou compartilhar este repositório, confirme que nenhum arquivo contém dados reais de cliente.

Não versionar:

- `C:\PatchOps\inventario\oci_hosts.csv` real.
- Evidências reais em CSV, JSON, TXT, JPG ou LOG.
- OCIDs reais (`ocid1.`), IPs internos, hostnames reais, nomes de tenant, compartments ou Identity Providers.
- Arquivos `~/.oci/config`, chaves privadas, `security_token`, logs de autenticação ou qualquer credencial.

Use sempre `DryRun` antes de criar ou excluir backups. A exclusão real de backups deve exigir revisão operacional e autorização formal.

## EN-US

Before publishing or sharing this repository, make sure no file contains real customer data.

Do not commit:

- The real `C:\PatchOps\inventario\oci_hosts.csv` file.
- Real CSV, JSON, TXT, JPG, or LOG evidence.
- Real OCIDs (`ocid1.`), internal IPs, real hostnames, tenant names, compartments, or Identity Providers.
- `~/.oci/config`, private keys, `security_token`, authentication logs, or any credential.

Always use `DryRun` before creating or deleting backups. Real backup deletion should require operational review and formal authorization.
