# OCI Backup Manager v1.0

**Product line:** Technova PatchOps  
**Author:** André Rodrigues  
**Status:** operational for controlled pilot

**OCI Backup Manager v1.0** is a PowerShell module for controlled creation, auditing, validation, and governance of **Boot Volume** backups in Oracle Cloud Infrastructure (OCI). It relies on the inventory generated by **OCI Inventory Manager v1.0** and is designed for PatchOps workflows, operational evidence, and Go/No-Go validation before critical maintenance windows.

## What it does

- Reads the standard inventory at `C:\PatchOps\inventario\oci_hosts.csv`.
- Creates Boot Volume backups by host or by filter.
- Supports `FULL` and `INCREMENTAL` backups.
- Provides `DryRun` mode to validate scope without creating resources.
- Generates backup history/status reports.
- Validates whether a recent `AVAILABLE` backup exists before patching.
- Deletes OCI backups only by OCID or CSV, with `DryRun` and strong confirmation.
- Produces CSV, JSON, TXT, and JPG evidence.
- Maximizes PowerShell on the primary monitor and captures visual evidence with the Windows date/time when the taskbar is visible.
- Includes guardrails to reduce operational risk in customer environments.

## What it does not do

- It does not replace a corporate backup policy.
- It does not replace change approval, CAB, or customer authorization.
- It does not validate application-level consistency after backup.
- It should not be used for real backup deletion without formal review.
- It should not be published with real customer inventories, evidence, or sensitive data.

## Operational menu

```text
1) CREATE REAL BACKUP by host(s)
2) DRYRUN by host(s)
3) CREATE REAL BACKUP by filter
4) DRYRUN by filter
5) Backup report by host
6) DELETE OCI backups by OCID/CSV
7) VALIDATE recent backup for patch
8) Exit
```

## Requirements

- Windows 10/11 or Windows Server with PowerShell 7.
- OCI CLI installed and available in `PATH`.
- OCI CLI profile configured, usually `DEFAULT`.
- OCI authentication through `security_token` or a valid OCI session.
- Inventory CSV generated by OCI Inventory Manager v1.0.
- IAM permissions to query instances, Boot Volume Attachments, and Boot Volume Backups.
- Additional IAM permissions to create or delete backups when those modes are used.

## Quick start

```powershell
cd C:\PatchOps\scripts
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force
Unblock-File .\OCI-Backup-Manager-v1.0.ps1
.\OCI-Backup-Manager-v1.0.ps1
```

### Host DryRun

```powershell
.\OCI-Backup-Manager-v1.0.ps1 -Hosts "APP01,APP02" -DryRun -NoMenu
```

### Real backup by host

```powershell
.\OCI-Backup-Manager-v1.0.ps1 -Hosts "APP01" -BackupType FULL -ForceCreateBackup -NoMenu
```

### Existing backup report

```powershell
.\OCI-Backup-Manager-v1.0.ps1 -Hosts "APP01,APP02" -BackupStatusReport -NoMenu
```

### Recent backup validation before patch

```powershell
.\OCI-Backup-Manager-v1.0.ps1 `
  -Hosts "APP01,APP02" `
  -RecentBackupValidation `
  -RecentBackupMaxAgeHours 24 `
  -NoMenu
```

### Deletion DryRun by CSV

```powershell
.\OCI-Backup-Manager-v1.0.ps1 `
  -DeleteBackupMode `
  -BackupDeleteInputCsv "C:\PatchOps\evidenciasackup-manager\status.csv" `
  -DryRun `
  -NoMenu
```
