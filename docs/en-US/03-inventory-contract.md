# CSV inventory contract

By default, the script uses:

```text
C:\PatchOps\inventario\oci_hosts.csv
```

This file should be generated by OCI Inventory Manager v1.0 or follow a compatible contract.

## Recommended columns

| Column | Usage |
|---|---|
| Hostname | Main host name |
| FQDN | Fully qualified DNS name, if available |
| HostnameLabel | OCI VNIC/hostname label, if available |
| State | Instance state, such as RUNNING or STOPPED |
| Region | OCI region |
| CompartmentName | Compartment name |
| CompartmentOCID | Compartment OCID |
| InstanceOCID | Instance OCID |
| BootVolumeOCID | Boot Volume OCID |
| PrivateIP | Private IP address |
| PatchGroup | Patch group |
| Application | Related application/service |

## Security rules

- Do not publish real inventories.
- Do not publish real OCIDs in public repositories.
- Do not publish real internal IP addresses.
- Use `examples/oci_hosts.sample.csv` as a sanitized model.
