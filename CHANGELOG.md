# Changelog / Histórico / Historial

## v1.0

### PT-BR

Primeira versão operacional para piloto controlado.

Inclui:

- Backup de Boot Volume OCI por host.
- Backup de Boot Volume OCI por filtro.
- Seleção de backup `FULL` ou `INCREMENTAL`.
- `DryRun` por host e por filtro.
- Relatório de histórico/status de backups.
- Validação de backup recente para Go/No-Go de PatchOps.
- Exclusão controlada por OCID/CSV.
- Evidências CSV/JSON/TXT/JPG.
- Screenshot full screen com relógio/data do Windows.
- Auth guard para sessão OCI.
- Guardrails para ações reais e destrutivas.

### EN-US

First operational version for controlled pilot.

Includes:

- OCI Boot Volume backup by host.
- OCI Boot Volume backup by filter.
- `FULL` or `INCREMENTAL` backup selection.
- Host and filter `DryRun` modes.
- Backup history/status report.
- Recent backup validation for PatchOps Go/No-Go.
- Controlled deletion by OCID/CSV.
- CSV/JSON/TXT/JPG evidence.
- Full-screen screenshot with Windows date/time.
- OCI session auth guard.
- Guardrails for real and destructive actions.
